# Ollama 本地大模型部署与应用 - 学习笔记

## 一、 课堂交付内容 (基础准备)
### 1. 安装步骤
*   前往 Ollama 官网 (https://ollama.com/) 下载对应操作系统的安装包（本次使用 Windows/Mac 版）。
*   双击安装，完成后在终端输入 `ollama -v` 验证是否安装成功。

### 2. 选型理由
*   **选型**：Qwen2 (7B) 或 Llama3 (8B)。
*   **理由**：考虑到本机内存/显存容量（例如16GB），7B/8B 级别的模型在量化（4-bit）后大概占用 4-6GB 内存，既能保证日常问答、代码生成的较高准确率，又不会导致系统卡顿。

### 3. ≥5问对比表 (示例)
| 提问内容 | 模型A (Qwen 7B) 回答质量 | 模型B (Llama3 8B) 回答质量 | 评价 |

## 二、 作业 1：Ollama 官方文档学习 (Model 管理与 API)
通过阅读官方文档，整理了 3 条以前不知道但非常实用的用法：

1.  **自定义 Modelfile 控制模型行为**：
    以前以为只能拉取现成的模型。现在知道可以通过编写 `Modelfile` 文件（类似 Dockerfile），使用 `FROM` 指令继承基础模型，并通过 `PARAMETER` 设定 `temperature`（随机性，0-1之间，越低越严谨）、`num_ctx`（上下文长度）等，最后用 `ollama create my-custom-model -f ./Modelfile` 生成专属模型。
2.  **REST API 的流式输出与调用**：
    知道了不仅能在命令行对话，还能通过 `http://localhost:11434/api/chat` 发送 POST 请求。特别学到了在请求体中加入 `"stream": true`，可以实现类似 ChatGPT 的逐字打字机效果；设为 `false` 则等待全部生成完一次性返回。
3.  **环境变量修改模型存储路径与网络监听**：
    默认模型存在 C 盘，容易撑爆。学到了在系统环境变量中设置 `OLLAMA_MODELS` 来更改模型下载和存储路径。另外，通过设置 `OLLAMA_HOST=0.0.0.0`，可以让局域网内的其他设备（如手机、其他电脑）也能通过 API 访问这台主机的模型。

## 三、 作业 3：轻量级开源模型的离线部署复盘 (乡村学校场景)
**场景**：要在无网的乡村学校教室部署，我会按以下方案准备：

1.  **离线包准备**：
    *   在有网电脑上，下载 Ollama 的全平台安装包（.exe / .dmg / .tgz）。
    *   在有网电脑上运行 `ollama pull qwen:1.8b`，然后将模型文件（通常在 `~/.ollama/models/blobs` 目录下）打包。
    *   准备一个轻量级的 Web 聊天界面（如打包好的 Open WebUI 离线镜像，或使用纯前端 HTML 调用本地 API 的静态页面）。
2.  **模型选择**：
    *   乡村学校电脑配置通常较低（大概率是 8G 内存、核显、甚至老旧机械硬盘）。
    *   不能选 7B 以上，**必须选择 1.8B 或 0.5B 的 4-bit 量化模型（如 Qwen1.5-1.8B-Chat）**。这个量级的模型推理速度尚可，且能应对基础的知识问答。
3.  **内存预算**：
    *   8GB 内存的电脑，系统占用约 3GB。
    *   1.8B 模型加载约需 1.5GB - 2GB 内存，加上上下文开销，总内存占用控制在 5GB 以内，确保不出现 OOM (Out of Memory) 卡死现象。
    *   如果仅有 4GB 内存的极老设备，则降级使用 0.5B 模型。
4.  **部署步骤**：拷贝安装包 -> 拷贝模型文件夹 -> 配置环境变量指向模型路径 -> 双击启动 -> 浏览器打开本地 Web UI。
